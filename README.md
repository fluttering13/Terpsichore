# Terpsichore

Terpsichore 是一款為舞者設計的 Flutter 練習工具，將影片跟跳、A/B 動作比較、音樂分軌與循環練習整合在同一個 App。所有媒體處理與 AI 音軌分離都在裝置本機完成，適合排舞、拆動作、校正節拍及反覆練習指定段落。

## 主要功能

### 學習模式

- 匯入本機舞蹈影片作為參考畫面 A。
- 視需要開啟前鏡頭 B，即時比對自己的動作；B 預設關閉。
- 調整播放速度、精準拖曳時間軸。
- 自訂循環起點與終點，支援重複播放及每輪休息倒數。
- 一鍵回到目前循環範圍的開頭。
- 透過兩次標記校正第一個八拍，顯示目前是第幾個八、第幾拍。
- 以八拍快速選取循環段落，再用時間軸細調。
- 錄製並保存自己的 B 畫面；錄影輸出選項已預留後續 A+B 合成功能。

### A+B 分析

- 同時載入參考影片 A 與自己的影片 B。
- 分別設定兩支影片的裁切範圍、播放速度與鏡像方向。
- 使用共用時間軸同步播放、暫停與定位。
- 切換上下或左右排列，並可鎖定畫面方向。
- 輸出 A+B 並排影片，或只輸出 B。
- 自訂輸出資料夾，輸出後可保存到媒體庫或分享至其他 App。

### 純音樂練習

- 匯入音訊或影片，直接使用原聲進行練習。
- 使用 AI 在本機分離六種聲部：鼓、貝斯、人聲、吉他、鋼琴及其他聲音。
- 自由多選聲部並建立練習混音。
- 循環練習期間可直接點亮或關閉各聲部，切換時保留播放位置與循環設定。
- 顯示共用時間軸上的對齊多軌波形，方便從振幅峰值判斷重拍位置。
- 點擊或拖曳任一波形即可定位；播放頭與循環範圍會同步顯示於所有音軌。
- 支援播放速度、循環範圍、重複播放、休息倒數及一鍵回到循環開頭。
- 波形與混音結果會快取，後續載入不必重複處理。

### 練習專案

三種模式都能保存目前狀態並於下次繼續：

- 為專案命名、更新、重新命名或刪除。
- 載入後恢復媒體來源、播放位置及模式相關設定，並保持暫停。
- 學習模式保存循環、速度、八拍校正、鏡頭與錄影輸出選項。
- A+B 分析保存兩支影片的裁切、速度、鏡像、版面及輸出設定。
- 純音樂練習保存聲部選擇、分軌結果、波形、速度及循環設定。
- 專案影片會複製到 App 管理的文件目錄，避免系統清除暫存來源後無法載入。

## 本機處理與隱私

- 影片合成、音訊準備、混音與 AI 六軌分離都在裝置本機執行。
- 媒體不會為了分析或分離而上傳到伺服器。
- AI 模型首次使用時需要網路下載，完成後會快取在裝置上。
- AI 模型約 136 MB；六軌分離需要較多記憶體與處理時間，實際速度取決於裝置效能及音樂長度。

## 技術架構

- Flutter / Dart
- `video_player`：影片播放與定位
- `just_audio`：音訊播放
- FFmpeg：影片輸出、音訊轉換與多聲部混音
- ONNX Runtime：裝置端 AI 音軌分離
- Camera：前鏡頭預覽與錄影
- DDD 風格的功能邊界，將核心規則、Flutter UI 與平台實作分離

```text
lib/
  core/
    learning_mode/          # 循環、休息與八拍規則
    ab_analysis/            # 雙軌裁切、速度與輸出規則
    music_practice/         # 聲部選擇與音樂循環規則
    saved_projects/         # 共用練習專案資料模型
    shared_video_playback/  # 共用影片值物件
  entrypoints/mobile/       # Flutter 畫面與 UI 元件
  infrastructure/          # 媒體、相機、FFmpeg、ONNX、播放器與本機儲存
```

更完整的邊界說明請參考 [`docs/architecture.md`](docs/architecture.md)，平台權限與裝置需求請參考 [`docs/platform-setup.md`](docs/platform-setup.md)。

## 開發環境

- Flutter SDK（以 `pubspec.yaml` 指定的 Dart SDK 範圍為準）
- Android `minSdk 24` 或以上
- iOS 16.0 或以上
- 真機測試建議保留足夠儲存空間與至少約 1.1 GB 可用記憶體供 AI 分離使用

## 執行專案

```sh
flutter pub get
flutter run
```

執行檢查與測試：

```sh
flutter analyze
flutter test
```

建立 Android Debug APK：

```sh
flutter build apk --debug
```

輸出位置：`build/app/outputs/flutter-apk/app-debug.apk`

## 權限

Android 需要相機、麥克風及網路權限；iOS 需要相機、麥克風及照片圖庫用途說明。檔案選擇透過系統選擇器進行，不要求廣泛的儲存空間權限。詳細設定請見 [`docs/platform-setup.md`](docs/platform-setup.md)。
